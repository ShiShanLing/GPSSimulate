# GPSSimulate

Android 虚拟定位 App。通过地图选点或快捷定位，将手机 GPS 坐标模拟到指定位置。

---

## 一、开启开发者模式

1. 打开手机 **设置**
2. 进入 **关于手机**（小米/红米可能在「我的设备」里）
3. 找到 **版本号**（或「MIUI 版本」）
4. **连续快速点击 7 次**
5. 出现「您已处于开发者模式」提示即表示成功

---

## 二、配置模拟定位（必做）

1. 返回 **设置**
2. 进入 **更多设置** → **开发者选项**  
   （部分机型在「系统」→「开发者选项」）
3. 打开以下开关（建议全部开启）：
   - **USB 调试**（用电脑安装时需要）
   - **USB 安装**（小米/红米用电脑安装时需要）
   - **USB 调试（安全设置）**（小米/红米用电脑调试时需要）
4. 找到 **选择模拟位置信息应用**（或「模拟位置」）
5. 选择 **GPSSimulate**

> 首次打开 App 时，若未完成上述设置，屏幕中央会弹出提示框，按引导操作即可。设置完成后返回 App，提示会自动消失。

### 小米手机额外说明

若通过 Android Studio / 数据线安装失败，提示 `INSTALL_FAILED_USER_RESTRICTED`，请在开发者选项中打开 **USB 安装**。

---

## 三、安装 App

### 方式一：安装 APK（推荐）

1. 将 `app-release.apk` 传到手机
2. 在文件管理器中点击安装
3. 若提示「未知来源」，按系统指引允许安装

### 方式二：电脑安装

```bash
adb install -r app-release.apk
```

---

## 四、首次打开 App

安装后首次启动，请按提示授予权限：

| 权限 | 用途 |
|------|------|
| 位置信息 | 获取当前真实位置、在地图上定位 |
| 通知 | 模拟定位运行时在通知栏显示状态 |

位置权限建议选择 **仅在使用中允许** 或 **始终允许**。

---

## 五、使用方式

### 1. 地图选点

- **拖动地图**，将屏幕中心的图钉对准目标位置
- 底部会实时显示当前中心点经纬度
- 点击 **「开始模拟」** 开始注入虚拟 GPS
- 模拟过程中继续拖动地图，位置会自动更新
- 点击 **「停止模拟」** 恢复真实定位

### 2. 定位到当前位置

- 点击 **「当前位置」**，地图会跳到你真实的 GPS 位置
- 若正在模拟中，需先 **停止模拟** 再获取真实位置

### 3. 快捷定位（预设城市）

1. 点击地图右上角的 **书签图标**
2. 在下拉列表中选择城市（默认包含「苏州」）
3. 地图自动跳到该位置，可再点 **「开始模拟」**

### 4. 添加快捷定位

1. 点击右上角 **书签图标**
2. 选择 **「添加快捷定位…」**
3. 按以下格式输入（逗号分隔，空格会自动去除）：

```
苏州, 31.3167, 120.6167
```

4. 点击 **添加**，城市会保存到本地，重启 App 后仍然保留

**更多示例：**

```
上海, 31.2304, 121.4737
北京, 39.9042, 116.4074
```

## 六、验证是否生效

1. 在 GPSSimulate 中选好位置并点击 **「开始模拟」**
2. 通知栏应显示「正在模拟 GPS 位置」
3. 打开其他 App（如系统地图、天气）查看位置是否已变化

**建议：** 模拟时可在系统设置中 **关闭真实 GPS**，仅保留网络定位，可减少真实坐标与模拟坐标冲突。

---

## 七、注意事项

| 说明 | 详情 |
|------|------|
| 适用场景 | 开发调试、个人测试 |
| 地图数据 | 使用 OpenStreetMap，首次加载需联网，看过区域会缓存到本地 |
| 部分 App 无效 | 银行、支付、打车、游戏等可能检测模拟定位并拒绝服务 |
| 数据保存 | 自定义快捷定位保存在手机本地，卸载 App 或清除数据后会丢失 |
| 清除模拟 | 停止模拟，或在开发者选项中取消本 App 的模拟位置权限 |


## 九、版本发布（维护者）

每个版本通过 GitHub Releases 发布，推送 `v*` 标签后由 Actions 自动构建 APK 并上传。

### 首次配置（一次性）

在仓库中配置签名密钥（使用本地 `signing/release-keystore.jks`）：

```bash
./scripts/setup-ci-secrets.sh
```

### 发布新版本

```bash
# 发布 1.0.1：更新版本号、本地打包、打标签并推送
./scripts/release.sh 1.0.1 --push
```

仅打标签、稍后手动推送：

```bash
./scripts/release.sh 1.0.1
git push && git push origin v1.0.1
```

发布完成后，在 [Releases](https://github.com/ShiShanLing/GPSSimulate/releases) 页面可下载 `GPSSimulate-vX.Y.Z.apk`。
